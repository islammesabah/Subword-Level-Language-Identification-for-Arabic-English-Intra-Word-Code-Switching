# Subword-Level Language Identification for Arabic-English Intra-Word Code-Switching
Nowadays, multilingual speakers tend to switch between two or more languages in the same conversation. They switch between two languages in the same sentence or different sentences. This phenomenon is known as Code-Switching (CS). In addition, they can switch between morphemes from different languages in the same word (intra-word CS). These different types of CS are widely used on social media platforms, which generates a huge amount of CS data everyday. CS data needs to be analyzed and investigated for several Natural Language Processing (NLP) and linguistic tasks. One of the important NLP tasks is the automatic Language Identification (LID) task that should reach the intra-word CS level. LID on intra-word consists of segmenting the mixed words then tagging every segment with its language ID. The bachelor aims to create an Arabic-English corpus to apply the intra-word CS LID task on. We implemented two baseline models to apply LID task using Naive Bayes and character Bidirectional Long Short-Term Memory (Bi-LSTM) for Arabic-English text. Also, we implemented our main model using Segmental Recurrent Neural Networks (SegRNN). This model got the highest performance. After hyperparametrs tuning of this model it achieved the best performance which is equal to 94.92% F-score on all testing data for tagging task as well as 81.15% F-score for the mixed data only.
